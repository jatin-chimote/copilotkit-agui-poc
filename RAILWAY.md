# Railway Deployment
railway.toml contains configuration for Railway deployment.

## Deploy to Railway

[![Deploy on Railway](https://railway.app/button.svg)](https://railway.app/new/template?template=https://github.com/YOUR_USERNAME/copilotkit-agui-poc)

### Steps:
1. Click the "Deploy on Railway" button
2. Set environment variable: `OPENAI_API_KEY`
3. Railway will auto-deploy both frontend and backend
4. Access your app at the provided Railway URL

## Environment Variables Required:
- `OPENAI_API_KEY`: Your OpenAI API key
